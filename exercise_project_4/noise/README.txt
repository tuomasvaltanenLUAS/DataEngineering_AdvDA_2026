Noise, outliers (and even overlap), might seem extremely similar to each other.

... and to a certain extent, they are mitigated often with the exact same tools.

It's more about semantics and "philosophy" what qualifies strictly 
as noise or an outlier.

In this folder, only MAD and RANSAC are included, which are often considered 
as noise removal tools.

Autoencoders also can be used to mitigate noise, see the autoencoder -examples 
in exercise project 2 - examples (other_generic_examples => autoencoder -notebooks).
