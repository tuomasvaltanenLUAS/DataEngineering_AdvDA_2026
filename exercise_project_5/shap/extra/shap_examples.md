| Shap plots| Use case|
|---|---|
|[shap.plots.waterfall](https://shap.readthedocs.io/en/latest/example_notebooks/api_examples/plots/waterfall.html)| Inspecting rows |
|[shap.plots.scatter](https://shap.readthedocs.io/en/latest/example_notebooks/api_examples/plots/scatter.html)| Inspecting columns |

|[shap.plots.violin](https://shap.readthedocs.io/en/latest/example_notebooks/api_examples/plots/violin.html)| Inspecting datasets with their distributions and variance |
|[shap.plots.decision_plot](https://shap.readthedocs.io/en/latest/example_notebooks/api_examples/plots/decision_plot.html)| Looking for anomalies in predictions |
|[shap.plots.heatmap](https://shap.readthedocs.io/en/latest/example_notebooks/api_examples/plots/heatmap.html)| For checking to see which columns can be dropped (Or aren't making good enough connections to be meaningful.) |
|[shap.plots.image](https://shap.readthedocs.io/en/latest/example_notebooks/api_examples/plots/image.html)| For Object detection/Image classification |
|[shap.plots.text](https://shap.readthedocs.io/en/latest/example_notebooks/api_examples/plots/text.html)| For NLP, Text classifiers, Text-to-text, etc |
