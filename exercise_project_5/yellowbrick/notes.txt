Yellowbrick, potential visualizations you can try during the course

NOTE! It seems Python 3.12 doesn't work that well with Yellowbrick due to 
differences in scikit-learn API differences.

There's a folder that attempts to fix the problems with Python 3.12, but
it's not as stable as using Yellowbrick with Python 3.9 or 3.10.

See documentation:
https://www.scikit-yb.org/en/latest/api/index.html
