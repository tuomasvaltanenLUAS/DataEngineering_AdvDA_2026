This folder will contain helpful examples for exercise project 3 - feature engineering.

The contents will be roughly the following:

Task 1: high cardinality
- Target encoding (CategoryEncoders -module)
- Agglomerative clustering (advanced, optional)

Task 2: interaction features
- Manual interaction features
- DFS - Deep Feature Synthesis
- Cluster profiling

Task 3: Feature/dimensionality reduction
- PCA (Principal Component Analysis)
- AutoEncoders

Advanced tasks / tools (various use cases):
- t-SNE (dimensionality visualization / analysis)
- Kernel PCA
